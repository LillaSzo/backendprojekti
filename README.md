WordApp

In this project, the goal was to create a Spring Boot application for studying foreign languages using wordcards.
Users can create their own word decks in different categories and practice vocabulary in a structured way.

Main goal: understand the basics of Spring Boot and take that knowledge into practice. 

- Java
- Backend: Spring Boot
- Database: PostgreSQL

Topics covered:
- Model & View (Thymeleaf)
- Database & JPA (H2 Database, CrudRepository, Validation)
- REST Controller (GET/POST/PUT/DELETE requests, JSON, Postman)
- Spring Security (Authentication, Authorization)
- Unit testing
- External Database (PostgreSQL)

Features:
- Login, Logout, user registration
- User and admin roles
- Create, edit and delete decks
- Admins can create community decks, Users can join these decks or create their own
- Users can view, edit and delete only their own decks, admins have access to all decks
- Users can practice vocabulary using word cards
